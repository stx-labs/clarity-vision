# Clarity 6 extraction deck

An interactive technical slide deck explaining the Clarity 6 engine extraction,
including crate ownership, the `contract-call?` execution path, consensus gate
classification, benefits, tradeoffs, validation evidence, and the path to
Clarity 7.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open <http://localhost:3000>. Use the arrow keys, Page Up/Page Down, or swipe to
navigate. Press `O` for the slide overview.

## Validate

```bash
npm test
npm run lint
```
